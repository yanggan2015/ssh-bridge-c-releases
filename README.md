### Option A — GitHub Releases (zip)

→ [Releases](https://github.com/yanggan2015/ssh-bridge-c-releases/releases)

- `ssh_bridge_manager-windows-<VERSION>.zip` (contains both folders above)

### Option B — git clone this branch

```bash
git clone -b windows https://github.com/yanggan2015/ssh-bridge-c-releases.git
cd ssh-bridge-c-releases/ssh_bridge_manager
```

Run `run.bat` / `ssh_bridge_manager.exe`, or `../windows_manager/windows_manager.exe` for LAN discovery.
