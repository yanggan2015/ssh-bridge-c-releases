### Option B — git clone (latest tree)

```bash
git clone https://github.com/yanggan2015/ssh-bridge-c-releases.git
cd ssh-bridge-c-releases/ssh_bridge_manager   # Windows
# or: cd ssh-bridge-c-releases/ssh_bridge_manager-linux
```

Then run `run.bat` (Windows) / `./run.sh` (Linux), or the `ssh_bridge_manager` executable.
Open `使用说明.txt` / `USAGE.zh-CN.txt` for the full guide.
